# Houdini QT

A tiny installable PWA that gives one Houdini quick tip at a time.

## Current version
This version is fully client-side and contains a curated starter set of tips. It works without an AI API or backend.

## Install on Android
1. Put this folder on a static web host.
2. Open the site in Chrome on Android.
3. Use Chrome's menu -> Add to Home screen / Install app.
4. Launch "Houdini QT" from the home screen.

## Next step
An AI-backed version can replace the local tip list with a small backend endpoint. Keep any AI API key on the server, not inside the app.
